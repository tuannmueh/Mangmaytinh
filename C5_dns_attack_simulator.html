Bộ Nhớ Đệm Cache (Resolver):

So Sánh Chuẩn Kỹ Thuật 4 Kiểu Tấn Công DNS

Loại Tấn Công Mục Tiêu Bảo Mật Cơ Chế Kỹ Thuật Cốt Lõi Thành Phần Bị Ảnh Hưởng Giải Pháp Phòng Thủ Chuẩn
1. DoS / Khuếch Đại DNS Làm ngưng trệ dịch vụ (Tính sẵn sàng - Availability) Giả mạo IP nạn nhân + Gửi truy vấn nhỏ tới Open Resolver để thu về phản hồi khổng lồ (EDNS0 x50 lần) Băng thông mạng & Máy chủ nạn nhân Tắt Open Resolver public, cấu hình Response Rate Limiting (RRL), triển khai BCP 38 / uRPF chống giả mạo IP
2. Cache Poisoning (Kaminsky) Đánh cắp thông tin / Lừa đảo (Tính toàn vẹn - Integrity) Gửi truy vấn subdomains ngẫu nhiên, tràn ngập phản hồi giả đoán đúng ngẫu nhiên cả TxID (16-bit) và Source Port UDP (16-bit) Bộ nhớ đệm (Cache) của Recursive Resolver Triển khai chữ ký số **DNSSEC**, ngẫu nhiên hóa Source Port (Kaminsky Patch), cập nhật Resolver software
3. DNS Hijacking Chuyển hướng lưu lượng lâu dài (Kiểm soát cấu hình) Xâm nhập tài khoản Registrar, hack Router Wi-Fi hoặc chiếm quyền Server DNS chính thức để sửa bản ghi A/NS gốc Tài khoản Registrar, Router, Máy chủ Nameserver gốc Xác thực 2 lớp (MFA), Khóa tên miền (Registry Lock), Bảo mật tài khoản quản trị, Giám sát bản ghi
4. DNS Tunneling Đánh cắp dữ liệu / Kênh C2 ẩn nấp (Lạm dụng giao thức) Mã hóa dữ liệu nhạy cảm (Base64/Hex) chèn vào Subdomain truy vấn (`[Payload].attacker.com`) gửi qua UDP port 53 Tường lửa kiểm soát mạng (Firewall / IDS / IPS) Phân tích Entropy chuỗi tên miền, Kiểm soát tần suất truy vấn DNS Egress, Giám sát mẫu dữ liệu bất thường
